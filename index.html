Excel / CSV bulk upload

Upload .xlsx, .xls or .csv. The first row must contain column headings. Existing SKUs can be updated; new SKUs are added. Preview and validate the file before importing.
Recognised headings (case-insensitive): SKU, Product Name, Category, Variant, Quantity, Minimum Stock, Purchase Price, Selling Price, Supplier, Location, Status, Notes. Alternative headings such as Product, Stock, Qty, Cost and Price are also recognised.

Backup & restore

Cloud storage: Aapka data Supabase database me save hota hai (sirf aapke login ko dikhta hai). Phir bhi kabhi-kabhi JSON backup download karke rakho.

The full JSON backup includes products, stock movement history, activity log and settings. Restoring replaces the current data, so download a backup of the current data first.

Data & safety notes

  • Har change turant Supabase me save hota hai (upar status dekho).
  • Data Row Level Security se protected hai: har user ko sirf apna data dikhta hai.
  • Excel import ke liye internet chahiye (SheetJS library). CSV bina library ke chalta hai.
  • Ye tool Meesho account se automatically connect nahi hota.

Danger zone

Delete all local inventory only if you intentionally want to start fresh. This action cannot be undone unless you have a backup.
